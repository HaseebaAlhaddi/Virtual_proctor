🎓 #Smart Virtual Proctoring System

📌 ##Overview

This project presents a Smart Virtual Proctoring System designed to automatically detect cheating during online exams using Artificial Intelligence and Computer Vision techniques.

With the rapid growth of online education, ensuring exam integrity has become a major challenge. This system aims to provide a secure, efficient, and automated solution for monitoring students remotely.

---

🚀 ##Features

- 🎥 Real-time video monitoring using webcam
- 👁️ Eye tracking and gaze detection
- 🧠 Head movement analysis
- 🔊 Audio monitoring for suspicious sounds
- 🤖 Object detection using YOLO
- 📊 Automated alerts for suspicious behavior
- 🗂️ Logging and reporting system

---

🧠 ##Technologies Used

- Programming Language: Python
- Computer Vision: OpenCV, dlib
- Machine Learning: YOLO (Object Detection)
- Audio Processing: SpeechRecognition
- Database: MySQL
- Framework/Tools: XAMPP, VS Code

---

⚙️ ##System Architecture

The system works by:

1. Capturing video and audio from the user's device
2. Analyzing facial features and movements
3. Detecting objects in the environment
4. Monitoring abnormal behaviors
5. Generating alerts and reports
